# **set up guide**
## Insure python version 3.13.4 is installed

## Set up python virtual environment
```
python -m venv energy_ml_venv .\energy_ml_venv\Scripts\Activate.ps1
```

## Install packages
```
python -m pip install -r requirements.txt
```
## Run jupter notebook command
```
jupyter notebook
```

## Layout
- main.ipyn the notebook
- helper_functions.py is where helper functions for notebook is stored
- Energy_dataset.csv is the dataset
